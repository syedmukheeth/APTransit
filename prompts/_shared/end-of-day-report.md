# End of day report

Copy this block into `progress/daily-log.md` at the end of every day. Newest day on top.

Then the dev who merges last updates `progress/handoff.md`: the "Current state" section (git, what works, what is not done, decisions), any new gotcha, and the "Day N+1 notes" for tomorrow. Package READMEs change in the same PR as the code they describe.

```markdown
## Day NN · YYYY-MM-DD · Dev A or Dev B

**Done**
- 

**Merged PRs**
- 

**Carry over (starts tomorrow before the new prompt)**
- 

**Contract changes (packages/shared)**
- none

**Bugs found** (id, severity S1 to S3, one line)
- 

**Blockers or questions for the other dev**
- 

**Decisions needed (also added to decisions-log.md)**
- none
```
